**Weight and metabolic effects:** Intermittent fasting (IF) produces weight loss and metabolic improvements comparable to traditional continuous calorie restriction. All forms of IF beat eating without restriction, but **no consistent advantage over simple calorie counting** for most outcomes.

**Long-term data is weak:** Only 17 of 99 trials lasted 24+ weeks. Longer trials showed benefits only compared to unrestricted eating—not between IF and continuous restriction. Adherence drops substantially after 12 months (from ~80% to ~22% in whole-day fasting).

Common mild effects: fatigue, headaches, dizziness, constipation, nausea, hunger, irritability. One trial reported hypoglycemia leading to a fall; another reported electrolyte imbalances. These were generally manageable, but the safety data is short-term.

- Pregnant or breastfeeding individuals
- Children/teens
- History of eating disorders (this is a significant concern)
- Diabetes, heart, kidney, or liver disease
- Those on medications for blood pressure, blood sugar, or heart conditions
- Older adults, especially frail or with low muscle mass

## Best Approach for CPU-Bound Work Today: `ProcessPoolExecutor`

For CPU-bound tasks in current Python, `concurrent.futures.ProcessPoolExecutor` remains the best choice. It spawns separate processes, each with its own Python interpreter and GIL, effectively utilizing multiple CPU cores.

Here's a concrete example calculating Fibonacci numbers in parallel:

```python
import concurrent.futures
import time
from functools import lru_cache

# CPU-bound function (no I/O)
@lru_cache(maxsize=None)
def fibonacci(n: int) -> int:
    """Calculate nth Fibonacci number - pure CPU work."""
    if n < 2:
        return n
    return fibonacci(n - 1) + fibonacci(n - 2)

def compute_fibonacci(n: int) -> tuple[int, int]:
    """Wrapper to return both input and result."""
    result = fibonacci(n)
    return (n, result)

def main():
    # Numbers to compute (larger = more CPU-intensive)
    tasks = [35, 36, 37, 38, 35, 36, 37, 38]
    
    # Sequential execution
    print("Sequential execution:")
    start = time.perf_counter()
    sequential_results = [compute_fibonacci(n) for n in tasks]
    sequential_time = time.perf_counter() - start
    print(f"  Time: {sequential_time:.2f}s\n")
    
    # Parallel execution using ProcessPoolExecutor
    print(f"Parallel execution (using {len(tasks)} workers):")
    start = time.perf_counter()
    
    with concurrent.futures.ProcessPoolExecutor(max_workers=4) as executor:
        # map maintains order, submit is more flexible
        parallel_results = list(executor.map(compute_fibonacci, tasks))
    
    parallel_time = time.perf_counter() - start
    print(f"  Time: {parallel_time:.2f}s")
    print(f"  Speedup: {sequential_time / parallel_time:.2f}x")
    
    # Verify results match
    assert sequential_results == parallel_results
    print(f"\nResults: {parallel_results}")

if __name__ == "__main__":
    main()
```
